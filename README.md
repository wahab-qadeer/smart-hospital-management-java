# Smart Hospital Management System

A Java-based Smart Hospital Management System developed using Object-Oriented Programming and database connectivity.

## Features

- Patient management
- Doctor management
- Hospital record management
- Add and update records
- Search records
- Database connectivity
- Data storage and retrieval

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- SQL
- Database Connectivity

## Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Exception Handling
- Database Operations

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Create the required database.
4. Import the SQL file provided in the `database` folder.
5. Configure your local database username and password.
6. Run the main Java file.
